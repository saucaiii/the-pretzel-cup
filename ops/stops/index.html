Delivery Stops

Edit drop sizes, basket type, and notes per stop. Drivers see the drop size as a cap on how much they can log as sold; bakers see the totals rolled up by route. Weekend values override weekday values on Saturdays and Sundays — leave them blank to use the weekday value. The Shorts flag means that stop gets the shorter-pretzel variant (baked only at Lynbrook; same price); flipping it posts an all-hands update automatically. Use the Route column to move a mis-assigned stop to the correct route in one click.
