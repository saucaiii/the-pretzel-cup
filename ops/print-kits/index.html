Print · Per-Store Bundles

Print kits for Staples

One row per active store. Each "Open bundle" button opens a page with all 5 kit pieces for that store, with the contact card's QR already personalized. Click Print · Save as PDF inside the bundle to get one PDF per store, then upload the lot to Staples.

Workflow

  1. Click Open bundle for a store. A new tab opens with the store's 5 pieces previewed.
  2. Inside that tab, click the gold Print · Save as PDF button. Chrome's print dialog opens.
  3. Choose destination Save as PDF, name it with the suggested filename (e.g. kit-fsq01.pdf), save to a folder on your Desktop.
  4. Mark the row as printed with the ✓ button so you don't repeat it.
  5. When you're through the list, upload every PDF to Staples' online print service and pick them up.
